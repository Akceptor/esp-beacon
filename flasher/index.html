Put the board in bootloader mode

This board has no auto-reset, so do this before clicking Connect:

  1. Hold the BOOT button.
  2. Tap RST (or replug USB) while still holding BOOT.
  3. Release BOOT, then click Connect and pick the board’s serial port.

Reading the output

Open a serial monitor at 115200 baud after flashing and resetting the board.

Receiver — one CSV line per packet it hears:

50787D4CA1E8,-32.0,12.8,13

FieldMeaning
chipIdWhich beacon sent it: that beacon’s Wi-Fi MAC address, unique per beacon.
rssi_dBmReceived signal strength. Closer to 0 is stronger: about −30 is very close, about −120 is the limit. Noisy packet to packet, so average several readings before using it for distance.
snr_dBHow far the signal is above the noise. Positive is clearly above it; SF12 can still decode down to about −20.
txPower_dBmThe transmit power the beacon says it used (13), read from the packet itself.

Lines starting with # are status: # listening, ok N rejected M every 10 s (rejected = packets that failed the CRC or weren’t from a beacon). The NeoPixel blinks blue per valid packet.

Beacon — transmits 2×/sec and prints a banner at boot (Beacon chipId … @ 868.0 MHz SF12 P13 dBm), then beat N about once a second, where N is the number of packets sent. A txerr after it means the radio reported a failed send. The NeoPixel blinks green per transmit.
